# 🛡️ รายงานการแก้ไขระบบเชื่อมต่อ Drami Online (Colyseus v0.16)

เอกสารนี้สรุปปัญหาที่เกิดขึ้นและแนวทางการแก้ไขทั้งหมดที่ทำให้ระบบกลับมาใช้งานได้ตามปกติ

---

## 🔍 ปัญหาที่พบ (Root Causes)

### 1. การเปลี่ยนแปลงของ API (Breaking Changes ใน Colyseus v0.16)
นี่คือสาเหตุหลักที่ทำให้คุณแก้ไขเองได้ยากมาก เพราะคู่มือส่วนใหญ่ในอินเทอร์เน็ตยังเป็นของเวอร์ชันเก่า (v0.15 ลงไป)
*   **ปัญหา:** ในเวอร์ชัน 0.16 (และ `@colyseus/schema` 3.0) คำสั่ง `room.state.players.onAdd` ได้ถูก **"ตัดออก"** ไปแล้ว ทำให้เมื่อ Client พยายามเรียกใช้งานจะเกิด Error ว่า `undefined` ทันที
*   **ทำไมถึงแก้นาน:** เพราะแม้เวอร์ชันจะตรงกัน (0.16 ทั้งคู่) แต่รูปแบบการเขียนโค้ด (Syntax) ต้องเปลี่ยนใหม่ทั้งหมดไปใช้ระบบ **Proxy**

### 2. ปอร์ตทำงานค้าง (Port EADDRINUSE)
*   **ปัญหา:** บางครั้งเมื่อเราปิดหน้าต่าง CMD ไปแล้ว แต่กระบวนการของ Node.js ยังคงค้างอยู่ใน RAM ทำให้เมื่อรันใหม่มันฟ้องว่าพอร์ต 2567 ถูกใช้งานอยู่ (Address already in use)
*   **ผลกระทบ:** เซิร์ฟเวอร์รันไม่ขึ้นจริง ทำให้ Client เชื่อมต่อไม่ได้

### 3. ข้อจำกัดของ Svelte (Reserved Symbol)
*   **ปัญหา:** ใน Svelte เครื่องหมาย `$` ถูกจองไว้สำหรับ Store เท่านั้น การนำมาใช้เป็นชื่อตัวแปรทั่วไป (เช่น `const $ = ...`) จะทำให้ Vite คอมไพล์ไม่ผ่านและเกิด Error 500
*   **การแก้ไข:** ต้องเปลี่ยนชื่อตัวแปรส่งเป็นชื่ออื่นที่สื่อความหมายแทน

## 🛠️ แนวทางการแก้ไขที่ดำเนินการไป

### 1. อัปเกรดโค้ดเป็นรูปแบบ v0.16 (The Proxy Pattern)
ได้เปลี่ยนวิธีการดึงข้อมูลจาก State ในไฟล์ `client/src/lib/game/Game.svelte` จากเดิม:

```typescript
// ❌ แบบเก่า (0.15) - ใช้งานไม่ได้แล้ว
room.state.players.onAdd((player, sessionId) => { ... });
```

เป็นรูปแบบใหม่ที่ใช้ **`getStateCallbacks`**:

```typescript
// ✅ แบบใหม่ (0.16) - ถูกต้องตามมาตรฐาน
import { getStateCallbacks } from "colyseus.js";
const callbacks = getStateCallbacks(room);

// ใช้ callbacks() ครอบ state เพื่อใช้งาน onAdd/onRemove
callbacks(room.state).players.onAdd((serverPlayer, sessionId) => {
    // ใช้ callbacks() ครอบ object ลูกเพื่อใช้งาน onChange
    callbacks(serverPlayer).onChange(() => {
        // อัปเดตข้อมูล
    });
});
```

### 2. ล้างโปรเซสที่ค้างอยู่
ผมได้ทำการตรวจสอบและยุติการทำงานของ Node.js ที่ค้างอยู่ในพอร์ต 2567 และ 5173 ก่อนจะเริ่มรันระบบใหม่ทั้งหมด เพื่อให้มั่นใจว่าไม่มีโค้ดเก่าค้างอยู่

## 💡 คำแนะนำสำหรับนักพัฒนา

หากในอนาคตคุณเจอปัญหา **"Offline"** หรือ **"undefined (reading onAdd)"** ให้ตรวจสอบดังนี้:
1.  **เช็ค Console ใน Browser (F12):** สำคัญที่สุด เพราะมันจะบอก Error ตัวแดงๆ ว่าบรรทัดไหนพัง
2.  **อ้างอิง Migration Guide:** หากใช้เวอร์ชัน 0.16 ต้องดู [Migrating to 0.16](https://docs.colyseus.io/migrating/0.16/) เสมอ
3.  **ระวังการใช้ `$` ใน Svelte:** อย่าใช้ตัวแปรชื่อ `$` เพียงลำพังในไฟล์ `.svelte`

**ตอนนี้ระบบรันอยู่ปกติทั้ง Backend และ Frontend สามารถเข้าเล่นได้เลยครับ!** 🎮✨
