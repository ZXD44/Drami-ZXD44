# ⚡ ระบบ Life Skills & การเก็บเกี่ยวทรัพยากร (Master Specification)

## 1. ภาพรวมระบบ (System Overview)
ระบบ Life Skills เป็นหัวใจหลักในการคราฟต์ไอเทมและเศรษฐกิจในเกม Drami Online ผู้เล่นสามารถพัฒนาทักษะสายอาชีพนอกเหนือจากการเก็บเลเวลต่อสู้

---

## 2. ทักษะหลักทั้ง 4 สาย (Core Skills)

| ทักษะ | อุปกรณ์ | แหล่งทรัพยากร | ผลผลิตที่ได้รับ |
| :--- | :--- | :--- | :--- |
| **🪵 ตัดไม้ (Woodcutting)** | ขวาน (Axe) | ต้นบีช (Beech Tree), ต้นเมเปิ้ล (Maple Tree) | ไม้ซุงบีช (`log_beech_item`), ไม้ซุงเมเปิ้ล (`log_maple_item`) |
| **⛏️ ทำเหมือง (Mining)** | อีเตอร์/พลั่ว (Pickaxe) | กองหินแร่ (Stone/Iron Ore) | แร่เหล็ก, หินก่อสร้าง, อัญมณีล้ำค่า |
| **🌾 ทำฟาร์ม (Farming)** | จอบ/เคียว (Sickle) | แปลงมะเขือเทศ (Tomato), ต้นพืชสมุนไพร | ผักสด, วัตถุดิบปรุงยาเพิ่มเลือด (HP Potion) |
| **⚔️ การต่อสู้ (Combat)** | ดาบ คทา ธนู | มอนสเตอร์ป่า | EXP ตัวละคร, เงิน Gold, อุปกรณ์สวมใส่ |

---

## 3. วงจรการทำงาน (Harvesting Loop)
1. **ผู้เล่นเดินเข้าใกล้ต้นไม้/แร่** (ระยะห่างไม่เกิน 64px)
2. **คลิกหรือแตะที่ทรัพยากร**:
   - ตัวละครหยุดเดินและหันหน้าเข้าหาเป้าหมาย
   - หลอดโหลดความคืบหน้า (Gathering Progress Bar) จะปรากฏขึ้น (เช่น ใช้เวลา 2.5 วินาที)
3. **ส่งการยืนยันไปยัง Server (Colyseus Authoritative)**:
   - เซิร์ฟเวอร์ตรวจสอบตำแหน่ง (ป้องกันการข้ามแมพมาเก็บ)
   - สุ่มจำนวนและดรอปไอเทมเข้า `Inventory` ของผู้เล่น
   - เพิ่มค่า EXP ในทักษะนั้นๆ เมื่อ EXP เต็มจะเลเวลอัป (`Level Up!`)
4. **Respawn Cycle**:
   - ทรัพยากรบนแมพจะเปลี่ยนสถานะเป็นตอไม้/ก้อนหินว่างเปล่า
   - เซิร์ฟเวอร์จับเวลา Respawn (เช่น 45 วินาที) ก่อนงอกขึ้นมาใหม่ให้เก็บเกี่ยวได้อีกครั้ง
