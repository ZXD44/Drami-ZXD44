# คู่มือโครงสร้างไฟล์ (LPC Asset Structure Guide - Thai)

คู่มือนี้สรุปความหมายของโฟลเดอร์ต่างๆ ในโปรเจกต์หลังจากที่มีการจัดโครงสร้างใหม่ เพื่อให้ค้นหาและใช้งานได้ง่ายขึ้น

---

## 👥 1. กลุ่มตัวละครและเพศ (Genders & Bases)

| โฟลเดอร์ | คำแปล | คำอธิบาย |
| :--- | :--- | :--- |
| `male` | **ชาย** | หุ่นตัวละครชายมาตรฐาน |
| `female` | **หญิง** | หุ่นตัวละครหญิงมาตรฐาน |
| `child` | **เด็ก** | หุ่นตัวละครเด็กเล็ก |
| `muscular` | **ชายกล้ามเนื้อ** | หุ่นตัวละครชายแบบเน้นกล้ามเนื้อ บึกบึน |
| `pregnant` | **คนท้อง** | หุ่นตัวละครหญิงตั้งครรภ์ |
| `teen` | **วัยรุ่น** | หุ่นตัวละครหญิงช่วงวัยรุ่น (ตัวเล็กกว่า female) |
| `shared` | **ทั่วไป** | ไอเทมที่ใช้ร่วมกันได้ทุกเพศ (เช่น อาวุธ, โล่, ไอเทมบางอย่าง) |

---

## 📦 2. หมวดหมู่ไอเทม (Categories)

| โฟลเดอร์ | คำแปล | ตัวอย่างไอเทมที่อยู่ด้านใน |
| :--- | :--- | :--- |
| `body` | **ร่างกาย** | สีผิวต่างๆ (Bodies), รอยแผล (Scars), รอยสัก |
| `hair` | **ทรงผม** | ทรงผมชาย/หญิง, หนวด (Beards), เครา (Mustaches) |
| `head` | **ส่วนหัว** | สีตา (Eyes), ทรงหู (Ears), ใบหน้า |
| `torso` | **ลำตัว / เสื้อ** | เสื้อทุกประเภท, ชุดเกราะหน้าอก, ชุดชั้นใน |
| `arms` | **แขน** | ถุงมือ (Gloves), ปลอกแขน, เกราะไหล่ (Shoulders / Bauldron) |
| `legs` | **ส่วนขา** | กางเกง, กระโปรง, เกราะช่วงขา |
| `feet` | **ส่วนเท้า** | รองเท้าบูท, รองเท้าหนัง, รองเท้าผ้าใบ |
| `hat` / `headwear` | **หมวก** | หมวกนักรบ, มงกุฎ, ผ้าคลุมศีรษะ |
| `weapon` | **อาวุธ** | ดาบ, ธนู, ไม้เท้า, หอก |
| `shield` | **โล่** | โล่ประเภทต่างๆ |
| `backpack` | **กระเป๋า** | กระเป๋าสะพายหลัง, ตะกร้า |
| `cape` | **ผ้าคลุม** | ผ้าคลุมหลัง |

---

## 🎬 3. ท่าทางตัวละคร (Animations)
ในแต่ละชื่อไอเทม จะมีไฟล์แยกตามท่าทางหลัก ดังนี้:

*   `walk`: ท่าเดิน (4 ทิศทาง)
*   `run`: ท่าวิ่ง
*   `idle`: ท่ายืนอยู่เฉยๆ
*   `slash`: ท่าฟัน (ดาบ/อาวุธมีคม)
*   `thrust`: ท่าแทง (หอก/คทา)
*   `shoot`: ท่ายิงธนู
*   `spellcast`: ท่าร่ายเวทมนตร์ (ยกมือ)
*   `hurt`: ท่าบาดเจ็บ หรือ ท่าตาย (ล้มลง)
*   `sit`: ท่านั่ง
*   `jump`: ท่ากระโดด

---

## 💡 วิธีการใช้งาน
1. **ค้นหาภาพ:** เข้าไปที่ `[เพศ] / [หมวดหมู่] / [ชื่อไอเทม]` คุณจะเห็นไฟล์ภาพแยกตามท่าทาง
2. **การอ้างอิงในโค้ด:** ใช้ไฟล์ `item-metadata.js` ซึ่งผมได้อัปเดตพาธให้ตรงตามโครงสร้างนี้ไว้หมดแล้วครับ
