# เครื่องมือสร้างตัวละคร LPC (LPC Spritesheet Character Generator)
=============================================

โปรแกรมนี้รวบรวมงานศิลปะตัวละครทั้งหมดที่เคยสร้างขึ้นภายใต้โครงการ [LPC](https://lpc.opengameart.org) จนถึงปัจจุบัน

ทดลองใช้งานได้ที่ [คลิกที่นี่](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/)

โครงการ Liberated Pixel Cup เป็นความร่วมมือของศิลปินชั้นนำมากมายที่ร่วมกันสร้างสรรค์ภาพกราฟิก (Sprites) ให้กับโครงการนี้
**หากคุณต้องการนำภาพเหล่านี้ไปใช้ในโปรเจกต์ของคุณ คุณ "จำเป็น" ต้องให้เครดิตทุกคนที่มีส่วนร่วมในภาพที่คุณเลือกใช้** สามารถดูรายละเอียดวิธีการให้เครดิตได้ที่ด้านล่าง

#### วิธีการให้เครดิตที่ถูกต้อง:
คุณสามารถทำได้โดย:
1.  นำไฟล์ **`CREDITS.csv`** แนบไปกับโปรเจกต์ของคุณ
2.  แสดงรายชื่อศิลปินในหน้า "Credits" ของเกมคุณให้ชัดเจน

### 💻 วิธีการรันโปรเจกต์ในเครื่อง (Development)

เนื่องจากระบบความปลอดภัยของเบราว์เซอร์ปัจจุบัน การเปิดไฟล์ `index.html` ตรงๆ อาจทำงานไม่ได้ คุณควรรันผ่าน Web Server ดังนี้:

**หากคุณมี Node.js:**
1.  รันคำสั่ง `npm install` ครั้งแรก
2.  รันคำสั่ง `npm run serve:open` เพื่อเปิดโปรแกรมผ่านบราวเซอร์ (ปกติจะใช้พอร์ต 8765)

### ❓ คำถามที่พบบ่อย (FAQ)

*   **ใช้ในเกมเชิงพาณิชย์ (ขายของ) ได้ไหม?**
    *   **ได้ครับ** แต่คุณต้องปฏิบัติตามเงื่อนไขของสัญญาอนุญาตของภาพนั้นๆ อย่างเคร่งครัด (โดยเฉพาะการให้เครดิต)
*   **จะนำภาพไปใช้ใน Engine อื่นได้อย่างไร (เช่น Unity, Godot)?**
    *   ภาพที่ได้จะเป็น Spritesheet มาตรฐาน คุณสามารถนำไปตัดเฟรม (Slice) ใน Engine ที่คุณใช้ได้เลย โดยดูคู่มือการเรียงเฟรมประกอบได้ในโปรเจกต์ครับ
